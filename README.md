## 🚀 Ikman.lk — Modern UI Redesign (Frontend)

A modern, responsive frontend redesign of the popular Sri Lankan online marketplace ikman.lk, built to improve user experience, visual hierarchy, and performance using contemporary web technologies.

This project focuses purely on **frontend/UI implementation**, reimagining the platform with a clean layout, intuitive navigation, and mobile-first responsiveness.

> ⚠️ This is an independent educational project and is not affiliated with or endorsed by ikman.lk.
>
> 🌐Site live at: https://tharinduthilakshana0thildezo.github.io/Ikman.lk-Redesign/

---

## 🌐 Project Overview

The goal of this redesign is to address common usability issues and modernize the interface of a large classified marketplace platform used across Sri Lanka for buying and selling goods. Such platforms typically include categories like electronics, vehicles, property, jobs, and services. ([Ikman][1])

### 🎯 Objectives

* Improve UI/UX design
* Enhance accessibility and readability
* Implement responsive layouts
* Optimize navigation flow
* Apply modern design principles
